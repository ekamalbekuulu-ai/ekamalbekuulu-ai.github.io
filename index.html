三分钟上手

不用懂 Git，也不用装软件，会点鼠标就行。

1

拿一串密钥

在 PageDrop 里点「打开 GitHub 生成密钥」，权限已经预填好了，登录后点一下绿色按钮就行。

2

把网页丢进去

单个 HTML、整个文件夹、或者一个 zip 都行。解压、建仓库、提交，它都替你做。

3

等一分钟拿网址

它会自动开好 GitHub Pages，构建完就把链接给你。想换自己的域名，页面上也能一步步配。
